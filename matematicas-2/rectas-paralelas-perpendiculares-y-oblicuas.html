Rectas paralelas, perpendiculares y oblicuas

Guíate con la nota y los ejemplos, y luego resuelve los ejercicios de cada Producto.

Nota

Dos rectas L₁ y L₂ son:

1
Si m₁ = m₂, entonces son paralelas (//).
2
Si (m₁)(m₂) = −1, entonces son perpendiculares (⊥).
3
Si no pasa ninguna de las anteriores, entonces son oblicuas.

Ejemplo 1

Comprueba si las rectas son paralelas (//) o perpendiculares (⊥).

L₁
2x − 3y + 9 = 0
−3y = −2x − 9
−3y−3 = −2x − 9−3
y = +23x + 3
m₁ = 23    b = 3
L₂
4x − 6y − 24 = 0
−6y = −4x + 24
−6y−6 = −4x + 24−6
y = +46x − 4
m₂ = 4 ÷ 26 ÷ 2 = 23    b = −4

Como m₁ = m₂ = 23, las rectas son paralelas (//).

Comprobación

L₁
y₁ = +23x + 3
m₁ = 23 = ΔyΔx
b₁ = 3
L₂
y₂ = +23x − 4
m₂ = 23 = ΔyΔx
b₂ = −4

Cada recta empieza en su b (donde corta al eje y). Desde ahí se avanza 3 a la derecha (Δx) y se sube 2 (Δy) para encontrar el siguiente punto. Como las dos tienen la misma pendiente, nunca se cruzan: son paralelas.

Ejemplo 2

Comprueba si las rectas son paralelas (//) o perpendiculares (⊥).

L₁
6x − 4y + 8 = 0
−4y = −6x − 8
−4y−4 = −6x − 8−4
y = +64x + 2
m₁ = 64 = 32    b₁ = 2
L₂
2x + 3y + 9 = 0
3y = −2x − 9
3y3 = −2x − 93
y = −23x − 3
m₂ = −23    b₂ = −3

m₁ = 32 ≠ m₂ = −23, entonces no son paralelas.

(32)(−23) = −66 = −1, entonces son perpendiculares (⊥).

Comprobación

L₁
y₁ = +32x + 2
m₁ = 32 = ΔyΔx
b₁ = 2
L₂
y₂ = −23x − 3
m₂ = −23 = ΔyΔx
b₂ = −3

L₁ empieza en b₁ = 2: se avanza 2 a la derecha (Δx) y se sube 3 (Δy). L₂ empieza en b₂ = −3: se avanza 3 a la derecha (Δx) y se baja 2 (Δy es negativo). Las dos rectas se cruzan formando un ángulo recto: son perpendiculares.

Ejercicios

¿Son paralelas, perpendiculares u oblicuas? Después haz la gráfica de comprobación.

Producto 1

  1. L₁: 3x + y − 5 = 0
    L₂: 6x + 2y + 8 = 0
  2. L₁: x − 2y + 6 = 0
    L₂: 2x + y − 7 = 0
  3. L₁: 4x − y + 3 = 0
    L₂: 2x + 3y − 9 = 0

Producto 2

  1. L₁: 3x − 4y + 8 = 0
    L₂: 4x + 3y − 6 = 0
  2. L₁: 5x + y − 2 = 0
    L₂: x + 5y + 10 = 0
  3. L₁: 2x + 5y − 10 = 0
    L₂: 4x + 10y + 30 = 0
Respuestas

Producto 1

  1. m₁ = −3, b₁ = 5
    m₂ = −3, b₂ = −4
    → Paralelas
  2. m₁ = 12, b₁ = 3
    m₂ = −2, b₂ = 7
    → Perpendiculares
  3. m₁ = 4, b₁ = 3
    m₂ = −23, b₂ = 3
    → Oblicuas

Producto 2

  1. m₁ = 34, b₁ = 2
    m₂ = −43, b₂ = 2
    → Perpendiculares
  2. m₁ = −5, b₁ = 2
    m₂ = −15, b₂ = −2
    → Oblicuas
  3. m₁ = −25, b₁ = 2
    m₂ = −25, b₂ = −3
    → Paralelas
